# 修复项目空状态按钮加号颜色

## 目标

让项目空状态主操作按钮中的加号与按钮文字统一显示为白色，恢复视觉一致性。

## 背景

- `ProjectsListPage` 在无项目时通过共享 `EmptyState` 渲染“创建第一个项目”按钮。
- `EmptyState` 的顶部 `Inbox` 图标是容器的直属子元素，操作按钮中的 `Plus` 是更深层的后代元素。
- 当前 `.page-state-empty svg` 会把两类图标都设置为信息色，覆盖主按钮原有的白色文字颜色；同一共享规则也影响应用空状态按钮。

## 范围

- 将空状态信息色限制到顶部直属图标。
- 让空状态内主按钮的图标继承按钮现有的白色前景色。
- 保持现有颜色变量、组件结构、文案、布局和交互不变。

## 不在范围

- 不重构按钮或空状态组件。
- 不新增颜色变量、依赖或视觉样式。
- 不调整其他页面布局与交互。

## 验收标准

- [x] 项目空状态“创建第一个项目”按钮中的加号显示为白色，并与按钮文字一致。
- [x] 共享空状态中的顶部 `Inbox` 图标仍使用现有信息色。
- [x] 应用空状态主按钮中的加号同样继承白色，避免同一根因遗留在兄弟调用处。
- [x] 按钮文案、布局、跳转行为和交互状态保持不变。
- [x] `make frontend-check` 通过。

## 风险与延期项

- 仅收窄一个 CSS 选择器，无已知兼容性风险或延期项。
